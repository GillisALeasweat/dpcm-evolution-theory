## 📖 概要（Abstract）

本プロジェクトは、現代進化総合説が直面している「確率論的パラドックス（短期間での急激な大改造）」「形態的停滞（Stasis：何千万年もの不変性）」および「適応プロセスの物語論的説明」という理論的課題を解決する統合進化理論体系**「多元深層時間・必然的幾何学収束モデル（The Deep-Time Parallel Convergence Model: DPCM v2.0）」**のインタラクティブ科学分析プラットフォームです。

進化発生生物学（エボ・デボ）、生物物理学、層位古生物学、集団遺伝学、および非線形力学系理論を統合し、主要な既存学説（現代進化総合説、断続平衡説、中立進化説/分子時計、形態学的構造主義/Evo-Devo、収斂必然説）との定量的・多角的対照検証を実現しています。

## 🌌 DPCM v2.0 の中核公理

### 1. 進化因果律のコペルニクス的転回（トップダウン幾何学）
* **従来の総合説（ボトムアップ）：** ランダムな変異の試行錯誤 ➔ 自然淘汰 ➔ 結果としての形態（天文学的確率の奇跡）。
* **DPCM（トップダウン）：** 宇宙の普遍的物理法則（流体力学・重力・光学）が規定する**「すり鉢（アトラクター）」が先行して存在** ➔ 共通OSの可動レールが先行 ➔ 分水嶺（鞍点）を突破した集団が不可逆的に安定解へと滑落（相転移）。

### 2. 共通根源システム（共通OS）の3大潜在パラメータ
海に入る遥か以前の中生代深層時間から、共通祖先の発生ツールキット内にすでに準備されていた生体力学的レバー：
1. **脊椎の背腹屈曲運動：** 陸上疾走（ギャロップ）の上下背骨しなり ➔ ドルフィンキック水平尾鰭推進への幾何学的合致。
2. **基質骨伝導システム：** 泥底・地表振動の下顎骨伝導 ➔ 水中音響ソナートランスデューサーへの合致。
3. **四肢発生ツールキット：** *Shh*（ソニック・ヘッジホッグ）シス調節領域（ZRS）やPitx1による肢芽形成のオン/オフスイッチ。

### 3. 周縁隔離小集団における非線形相転移（4ステップ）
1. **境界ニッチ周縁隔離：** 汽水域、河口泥地、林冠限界などの環境境界領域へ少数が隔離。
2. **潜在変異の顕在化：** 極限環境ストレスにより分子シャペロン（Hsp90等）の抑制が解除（遺伝的同化の始動）。
3. **遺伝的浮動による分水嶺（鞍点）突破：** 周縁小集団の遺伝的浮動によって適応度の谷間を不可逆的に突破。
4. **物理すり鉢への不可逆的滑落：** 物理法則の強烈な力学的淘汰圧により、幾何学的最適解が集団内に爆発的速度で固定（Stasisへ到達）。

### 4. 認識論的限界の解体（ゼロスタート神話の粉砕）
* 始新世以前にクジラ祖先が化石記録に認識されないのは骨がなかったからではない。耳胞（インボルクラム）以前の骨格は未分化原始哺乳類と解剖学的に同定できないという**古生物学の認識論的限界（見つかっていないのではなく見分けがついていない）**である。
* 陸上完成型が海に逃げて足を捨てて魚に戻る（可逆的進化物語）をドロの法則の生体力学に基づき粉砕。海洋化は水陸両用中立境界領域からの**「不可逆的二極展開」**。

## 💬 学術討論・想定反論への応答録（DISCUSSION.md）

主流派の現代総合説、分子時計系統学、古生物学から予想される主要な批判・反論に対して、詳細な学術論証と反証可能命題をまとめた [**`DISCUSSION.md`**](DISCUSSION.md) を公開しています：
1. **討論 1：Rocks vs. Clocks（分子時計の分岐年代 vs 中生代深層時間）**
   * 緩和分子時計の線形平滑化バイアスと、非線形相転移ダイナミクスによる解決
2. **討論 2：物理アトラクター先行説 vs 目的論（インテリジェント・デザイン等）**
   * 流体力学（ナビエ・ストークス方程式）と幾何光学による厳密な物理主義的エネルギー最小化の証明
3. **討論 3：ゼロスタート神話とインボルクラム以前の同定限界**
   * 骨格アポモルフィ（診断形質）以前の祖先骨格が未分化原始哺乳類と識別不能である認識論的境界
4. **討論 4：周縁隔離小集団における相転移の分子メカニズム**
   * 極限ストレス下でのHsp90分子シャペロン解除、Waddingtonの遺伝的同化、*Shh* ZRSシス調節エンハンサー
5. **討論 5：ドロの不可逆法則と水陸両用境界ニッチからの二極展開**
   * 陸上特化型の巻き戻し進化物語の破棄と、境界ニッチからの不可逆的二極分岐
